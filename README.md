🎯 Project Showcase

Here are the C projects I've completed, representing my learning path from beginner to intermediate:

1. project1_dynamic_array (Dynamic Array) 📦

My first implementation of a dynamic data structure. Through this project, I mastered dynamic memory management using 
"malloc" and 
"free", and understood how arrays can automatically expand to accommodate more elements.

2. project2_linked_list_basic (Linked List - Basic) 🔗

This is the code I wrote when first learning about linked lists, which helped me understand pointers and the basic concepts of linked storage. Although simple, it taught me how to connect multiple nodes through pointers and perform traversal operations.

3. project3_linked_list_advanced (Linked List - Advanced) ⚙️

Building upon the basic version, I refactored the code to be modular, encapsulating operations within functions. This version allowed me to practice writing cleaner, more maintainable code while also focusing on preventing memory leaks.

4. project4_linked_list_expert (Linked List - Expert) 🔥

This is my most advanced linked list implementation, featuring a complete code structure with separate header and source files. I've added linked list reversal, length calculation, and insertion at any position functions, making the implementation more comprehensive and practical. This project demonstrates my improved understanding of code organization and advanced algorithm implementation.

5. project5_string_functions (String Functions Library) 🔤

This project is my complete re-implementation of the standard C string library functions. By building these functions from scratch, I gained deep insight into:

- String manipulation: Understanding how strings are stored and manipulated in memory
- Pointer arithmetic: Mastering the use of pointers for efficient string operations
- Memory management: Learning proper handling of string termination characters
- Edge case handling: Implementing robust functions that handle all corner cases correctly

Key Functions Implemented:

- 
"mylen" - String length calculation
- 
"mycpy" - String copying
- 
"mycat" - String concatenation
- 
"mycmp" - String comparison
- 
"myncpy" - Length-limited string copy
- 
"myncat" - Length-limited string concatenation
- 
"myncmp" - Length-limited string comparison
- 
"mychr" - Forward character search
- 
"myrchr" - Reverse character search

Through this project, I learned how to write modular, well-documented code with comprehensive testing, reinforcing my understanding of fundamental C programming concepts.
